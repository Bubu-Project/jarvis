# 🤖 Jarvis - Autonomous AI Voice Assistant

Jarvis is a fully autonomous AI Voice Assistant built from scratch. Developed by a Mechanical Engineer transitioning into AI, this project integrates an Android frontend with a custom Python backend.

## ✨ Features
- **Hardware Control:** Control Camera, Flashlight, and Wi-Fi via voice.
- **Communication:** Send SMS and make Calls directly.
- **Coding Agent:** Generates Python code, saves it to GitHub, and executes it.
- **Multi-Agent Swarm:** Routes tasks to specific AI agents.
- **Human-like Interaction:** Uses a custom-trained 4B LLM for Hindi/English conversations.

## 🛠️ Tech Stack
- **Frontend:** Android (Kotlin)
- **Backend:** Python (FastAPI)
- **AI Models:** Custom 4B LLM (QLoRA), Whisper (STT)
- **APIs:** GitHub API, Edge-TTS
